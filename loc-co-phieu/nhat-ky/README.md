# Nhật ký gợi ý

`goi-y.json` do công cụ **tự ghi và tự cập nhật** sau mỗi lần lọc: mọi gợi ý MUA đã đưa ra, giá vào, mức cắt lỗ, mục
tiêu, lãi/lỗ đến hôm nay hoặc kết quả khi đã bán. Đừng sửa tay. Muốn xem bảng tính thì mở `ket-qua/nhat-ky-goi-y.csv`
(được tạo sau mỗi lần chạy), hoặc nhắn Claude "xem hiệu quả gợi ý".
